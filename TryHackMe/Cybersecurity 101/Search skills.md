# Shodan 
Shodan is a cybersecurity search engine that allows users to find and analyze internet-connected devices and check whether they are exposed or vulnerable online

The main purpose of Shodan is to help people:

- discover exposed or publicly accessible devices on the internet
- analyze cybersecurity risks
- find misconfigured systems
- support network and security research

# Virus Total

VirusTotal is an online security tool used to check whether a file, URL, or software is safe or contains malware.

It helps to:
- detect viruses, malware, and trojans
- analyze suspicious files or links
- check if a website is safe
- support cybersecurity investigation
